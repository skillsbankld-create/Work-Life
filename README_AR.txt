سلسلة Wellbeing at Work التفاعلية · Skills Bank

المحتويات:
- index.html : صفحة السلسلة (3 فيديوهات، نقاط XP، بادجات، شهادة)
- media      : الفيديوهات الثلاثة (كل واحد أقل من 25 ميجا)
- fonts      : الخطوط

الرفع على GitHub Pages:
1) اعمل Repository جديد (Public) وعلّم على Add a README file.
2) Add file ثم Upload files: افتح هذا الفولدر من File Explorer واسحب كل ما بداخله
   (index.html و media و fonts وباقي الملفات) إلى صفحة الرفع. لا تسحب الفولدر نفسه.
3) انتظر حتى يكتمل رفع الفيديوهات ثم Commit changes.
4) Settings ثم Pages ثم Branch: main و / (root) ثم Save.
5) بعد دقيقة أو اثنتين يظهر الرابط. جرّبه على الموبايل واللابتوب قبل إرساله.

ملاحظات:
- تقدّم المتدرب (النقاط والبادجات والشهادة) يُحفظ على جهازه فقط.
- الشهادة تُنشأ باسم المتدرب في النهاية ويمكن تحميلها PNG.
- قبل النشر العام: تأكد من رخصة الموسيقى والمؤثرات (Mixkit).
